## 1.1.0 — 2026-11-27

### Microsoft Store

- **Store updates ship with every release.** If you installed viewbus from the Microsoft Store, new versions now arrive there alongside the direct download, once Microsoft has reviewed them (usually within a few days).
- **A refreshed Store page** with new screenshots and a shorter, clearer description.

The Store rejected this version's package, so it never reached the Store. [1.1.1](https://viewbus.app/changelog/1.1.1) fixes that.

The app itself is the same as 1.0.0, so updating changes nothing for you. Your settings, themes, monitored sets and stored connections carry over untouched.
