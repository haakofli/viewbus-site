## 1.1.1 — 2026-11-27

### Fixes

- **The Microsoft Store accepts viewbus again.** The Store rejected the 1.1.0 package because of how it set up the `viewbus-mcp.exe` command that AI assistants use. The command is now part of the main app. It keeps the same path, so assistants you've already connected keep working.

The app itself is the same as 1.0.0, so updating changes nothing for you. Your settings, themes, monitored sets and stored connections carry over untouched.
